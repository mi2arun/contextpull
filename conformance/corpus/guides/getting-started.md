# Getting started

Welcome. This guide walks through installation and first use.

## Installation

### Requirements

You need Python 3.10 or newer and about 50 MB of disk space.

### Install with uv

Run `uv tool install example-cli`. The `--no-cache` flag skips the download cache.

#### Verifying

Run `example-cli --version` and confirm it prints a version string.

## First run

Run `example-cli init` in an empty directory. It creates a `config.toml` you can edit.

## Next steps

Read the configuration reference for every key in `config.toml`.
