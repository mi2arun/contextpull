# uv docs benchmark, 2026-09-14

Corpus: `astral-sh/uv` `docs/` (81 Markdown files), ingested by ContextPull into 603 sections with gpt-5.4-mini summaries. Eval set: 221 questions generated by ragbisect over those sections (`questions.jsonl`; 126 conceptual, 95 exact-lookup). k = 5.
